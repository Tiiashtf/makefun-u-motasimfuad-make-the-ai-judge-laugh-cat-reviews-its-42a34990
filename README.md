Entry for the make.fun bounty
[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990):
a program that writes one funny single-line one-star review from a house cat
about its human, under 200 characters, to `/output/entry.txt`.

## The line

> One star. He filled the bowl, shut the door, and sat in my sunbeam with his laptop. So I sat on his keyboard. Fair is fair.

123 characters — inside the 1–200 character gate.

The joke is one idea: the human does everything right (full bowl) and then
commits the one unforgivable crime — taking the cat's sunbeam for his laptop.
The cat's revenge is perfectly measured by cat standards: not the human's
work, his keyboard. "Fair is fair" lands the sting in the last three words,
deadpan, as if the cat is simply applying the house rules. It keeps the shape
of a real one-star review while the complaint goes somewhere only a cat
would go.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
deterministically — the same bytes on every run. Stdlib only, no network.
The output directory itself is never removed, only its contents.
